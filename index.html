Tentang Saya

Peneliti deteksi objek yang juga senang membangun perangkat lunak.

Saya mahasiswa Informatika di Institut Teknologi Dirgantara Adisutjipto (ITDA) Yogyakarta — kampus kedirgantaraan di kawasan Lanud Adisutjipto. Saat ini saya bekerja sebagai Object Detection Research Assistant, berkutat dengan dataset, anotasi, dan pelatihan model computer vision.

Di luar riset, saya aktif membangun aplikasi web — dari CodeIgniter 4 dan React, sampai bereksperimen dengan TensorFlow.js untuk membawa machine learning langsung ke browser. Saya juga penggemar berat Linux: menulis skrip optimasi sistem, menyusun dotfiles, dan men-tweak kernel.

Sebelumnya saya menjadi IT Executive di Adisutjipto Linux Community, aktif di HMF ITDA (Himpunan Mahasiswa Informatika), serta menempuh pembelajaran melalui Google Cloud Skills Boost dan memperoleh pengalaman industri bersama GMF AeroAsia dan Traveloka.
