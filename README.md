# pangaribowo.github.io

Situs portofolio personal **Fatahillah Alif Pangaribowo** — Object Detection Research Assistant di ITDA Yogyakarta & software developer.

🌐 **Live:** https://pangaribowo.github.io

## Fitur

- 🎨 Tema kosmik gelap dengan starfield canvas interaktif & efek aurora
- 🌍 Bilingual — Indonesia / Inggris (pilihan tersimpan otomatis)
- ⌨️ Efek mengetik pada role, animasi scroll-reveal, dan statistik count-up
- 🤿 Spotlight effect pada kartu proyek, avatar dengan orbit ring animasi
- 📱 Sepenuhnya responsif, tanpa build tool — HTML, CSS, dan JavaScript murni
- ♿ Menghormati `prefers-reduced-motion`

## Struktur

```
├── index.html    # Seluruh aplikasi (markup + style + script, single file)
└── README.md
```

## Menjalankan Lokal

Tanpa dependensi apa pun:

```bash
# buka http://localhost:8000
```

Otomatis melalui GitHub Pages dari branch `main` (root). Setiap push akan langsung tayang di https://pangaribowo.github.io.
